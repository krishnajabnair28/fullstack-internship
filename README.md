# Full Stack Blog Website

## Project Overview
This project is a Full Stack Blog Website developed as part of a 14-day Full Stack Development Internship. It allows users to create, view, edit, and delete blog posts using a Node.js and Express.js backend with an HTML, CSS, and JavaScript frontend.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Git
- GitHub

## Features
- Create blog posts
- View blog posts
- Edit existing blog posts
- Delete blog posts
- Responsive user interface
- Frontend and backend integration using Fetch API

## Project Structure
```
fullstack-internship/
│── index.html
│── blog.html
│── style.css
│── script.js
│── server.js
│── package.json
│── README.md
```

## How to Run the Project
1. Clone the repository.
2. Open the project in VS Code.
3. Install dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   node server.js
   ```
5. Open the website in your browser.
